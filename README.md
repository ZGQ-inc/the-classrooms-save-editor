# The Classrooms 存档编辑器 (The Classrooms Save Editor)

本项目是一个基于 Web 的纯静态 GUI 存档编辑器，专为恐怖探索游戏 *The Classrooms* 设计。  
全面适配游戏 **Update 0.10.2+**（版本号 `0.10.2.914`），完整支持主线剧情、无尽模式、自定义无尽模式、10槽位独立存档、换装试衣间及玩家预设档案。

![preview](https://the-classrooms.zgqinc.gq/preview.png)

---

## 🌟 功能列表

### 1. 核心与兼容性
* **全存档类型与 10 大存档槽位覆盖**：
  * **主线故事存档**：`Auto Save` 及 `Auto Save (Slot 2)` ~ `(Slot 10)`
  * **无尽模式存档**：`Non Linear` 及 `Non Linear (Slot 2)` ~ `(Slot 10)`
  * **无尽自定义模式存档**：`Non Linear Custom` 及 `Non Linear Custom (Slot 2)` ~ `(Slot 10)`（自动向下兼容并平滑升级旧版存档）
  * **角色试衣间预设**：`Character Presets`
  * **玩家档案**：`Player Profile` / `CustomCharacter`
* **双格式完美兼容**：
  * **JSON 文件**：原生支持 Steam 云存档目录中的纯文本 `.json` 文件。
  * **注册表 `.reg` 文件**：内置二进制 Hex 解析引擎，支持 Windows 注册表导出文件（自动识别 UTF-16LE 编码并转化为可编辑对象）。
* **多选与文件夹一键导入**：支持同时拖入多个存档文件，或直接选择 Steam `remote` 存档文件夹整体导入。
* **双模式分栏与智能切换**：左栏固定显示主线故事模式（Auto Save），右栏支持 **[ 🎮 标准 ] [ ⚙️ 自定义 ]** 模式无缝切换，不同存档槽位同屏管理互不干扰。
* **状态识别徽章**：顶部实时指示当前载入的文件格式（`JSON` / `REG`）以及已激活的存档模块与槽位序号（`Story (Slot N)` / `Endless` / `Custom` / `Presets` / `Profile`）。

---

### 2. 换装系统与试衣间 (Wardrobe)
* **八大装备部位管理**：
  * 上装 (Upper)、下装 (Lower)、鞋子 (Shoes)、帽子 (Hat)、连身装 (FullBody)、面部 (Face)、手腕 (Wrist)、腰部 (Waist)。
  * 直观卡片式展示，点击即可预览立绘、更换服饰或一键脱下。
  * 适配 0.10.2 耳机迁移：耳机道具全面归入面部/眼镜 (Face) 槽位，支持与任意帽子同时穿戴。
* **体型/性别一键切换**：支持在预设中自由切换男性（Male）与女性（Female）角色基础模型。
* **预设管理系统 (Preset Management)**：
  * **新建预设**：可基于官方角色预设模板派生新装扮。
  * **重命名 / 删除**：自由调整各预设名称与顺序。
  * **档案直修**：直接管理与修改 `Player Profile` 中的 `CustomCharacter`。
* **一键解锁自定义模式**：一键激活玩家档案中的“自定义模式（Custom Mode Unlock）”。
* **局内装备看板与一键同步**：
  * **局内装备状态**：实时对比 Auto Save、Non Linear 和 Non Linear Custom 各存档当前局内穿戴的衣物三件套。
  * **🔄 同步预设到局内**：一键将当前试衣间搭配的服装三件套直接写入所有已载入存档的局内装备。

---

### 3. 服装图鉴与一键入包 (Apparel Catalog)
* **151+ 全服装图鉴**：收录游戏全部官方服饰，配有原版高清立绘与中英双语名称：
  * **0.10.2 新增免费服饰**：细框眼镜（Thin Eyeglasses，多色适配）。
  * **0.10.2 新增内购服饰**：女仆装（Maid Dress，男款与女款独立全套）。
* **多维度筛选**：支持按部位、适用性别快速过滤，内置关键词模糊搜索框。
* **🎒 一键解锁全部服装入包**：一键将全部 151 款服装注入到所有已载入存档（Auto Save、Non Linear、Non Linear Custom）的背包中，自动计算连续槽位并智能去重。
* **单件快速加入背包**：在图鉴中直接点击“🎒 加入背包”，即刻添加到当前存档。
* **Steam 商店内购标注**：
  * 针对 Steam 商店 DLC 内购服装（泳池派对礼包、警察制服礼包、笑脸面具、女仆装），在试衣间卡片、图鉴和背包槽位均标有专属金色 `[🛒 Steam商店]` 标签并提示对应的礼包信息。

### 4. 玩家属性与无尽专属 (Player Stats)
* **奖票修改**：自由修改紫粉色奖票数量（最高支持 21 亿安全上限）。
* **手电筒电量**：可视化滑块无极调整电量（0-240），配备动态电量图标指示。
* **背包扩容**：自由设置背包等级（Level 1 - Level 3）。
* **无尽模式专属选项**：
  * 修改当前剩余生命值。
  * 开启 / 关闭“无限生命 (Infinite Lives)”。
  * 开启 / 关闭“可获得生命 (Can Get Lives)”。
  * 修改当前探索深度（Depth）。

---

### 5. 关卡与探索进度 (Level Progression)
* **故事模式（Auto Save）**：
  * 关卡磁带收集可视化。
  * **一键通关**：一键解锁所有主线关卡磁带。
* **无尽模式（Non Linear / Custom）**：
  * 自定义各个房间类型（如 Gym、Pool、Auditorium、Library 等）的访问次数计数器。

### 6. 物品栏与图鉴编辑器 (Inventory)
* **全类别支持**：
  * **可收集物品**（Collectables，固定 15 格）
  * **钥匙**（Keys，固定 15 格）
  * **钥匙卡**（Keycards，固定 24 格）
  * **档案**（Codex）
  * **磁带录像**（VHS）
  * **服装道具**（Apparel，自适应多行拓展）
* **网格交互与槽位保护**：
  * 真实还原游戏内网格布局，已修复普通物品栏误用自适应计算导致格子超出 15/24 格上限的问题。
  * 点击空槽位添加物品（带品类搜索和堆叠上限校验）。
  * 点击已有物品可修改堆叠数量、替换为其他物品或删除。
* **一键解锁收集**：
  * 🔓 **一键解锁全档案**（Unlock All Codex）
  * 🔓 **一键解锁全收集磁带**（Unlock All Collected Tapes）
* **实体与单据全屏查看器**：
  * 内置图片查看器，支持平移、缩放，全屏预览实体怪物立绘及档案单据原图。

### 7. UI/UX 与技术特性
* **纯静态运行**：无需安装环境，无需后端服务器，所有解析与导出均在浏览器本地内存安全完成，绝不上载用户数据。
* **多语言国际化 (i18n)**：原生支持简体中文 / 英文一键无缝切换。
* **暗黑主题风格**：与游戏氛围高度契合的高对比度暗黑视觉设计，配有平滑动画与 Toast 状态提示。
* **版本兼容检查**：通过 `version.txt` 校验存档版本，遇到版本变动时友好提示或平滑兼容。

## 📖 使用说明

### 1. 存档位置

#### Steam 云存档目录（推荐使用）
即便开启或关闭 Steam 云同步，游戏均优先在 Steam 客户端的本地云路径下读写明文 JSON 存档：
```text
C:\Program Files (x86)\Steam\userdata\<你的SteamID32>\2099110\remote
```
该目录下通常包含以下文件：
- `Auto Save` / `Auto Save (Slot 2)` ~ `(Slot 10)`：主线剧情模式存档
- `Non Linear` / `Non Linear (Slot 2)` ~ `(Slot 10)`：无尽模式标准存档
- `Non Linear Custom` / `Non Linear Custom (Slot 2)` ~ `(Slot 10)`：无尽模式自定义存档
- `Character Presets`：角色更衣室预设存档
- `Player Profile`：玩家自定义角色与系统解锁档案

> **提示**：建议在修改前先备份整个 `remote` 文件夹。修改完成后将导出的文件放回该目录覆盖即可。

#### Windows 本地注册表路径
如需直接编辑或恢复注册表数据，游戏注册表项位于：
```text
计算机\HKEY_CURRENT_USER\Software\Xefier Games and Hillcrest Games\The Classrooms
```
本编辑器支持直接导入导出完整的 `.reg` 文件，无需手动打开注册表编辑器换算十六进制。

---

### 2. 使用步骤
1. 打开 `index.html`（或访问在线部署页面）。
2. 点击 **“选择存档文件”**（可多选）或点击 **“选择文件夹”** 直接选中 Steam 的 `remote` 目录。
3. 页面将自动解析并激活顶部对应的存档徽章。
4. 切换标签页进行相应修改：
   - **基础属性**：修改奖票、手电筒、背包等级、无尽生命与深度。
   - **关卡磁带**：管理已收集的关卡磁带或一键通关。
   - **物品栏**：自由调整各分类背包槽位物品，或一键补全档案/磁带。
   - **换装系统**：管理 8 个槽位的服饰预设、切换性别、一键解锁自定义模式或一键全服饰入包。
5. 点击顶部的 **“💾 导出数据”**，浏览器将自动导出修改后的全部存档文件，覆盖回原存档路径即可进入游戏体验。
